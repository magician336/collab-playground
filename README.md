# collab-playground 🎪

一个专门用来**练手 GitHub 协作**的游乐场——在这里,提错 Issue、发砸 PR 都没关系,这正是它存在的意义。

## 🎮 三步玩法

### 第 1 步:提一个 Issue(30 秒)

点上方 **Issues → New Issue**,选一个模板:

- 🎁 **许愿**:希望这个仓库变成什么样?想看到什么好玩的内容?
- 🙋 **提问**:任何关于 Git / GitHub / 协作的问题,别怕问得基础

也可以只写一句自我介绍——这里欢迎任何形式的第一步。

### 第 2 步:留下你的第一个 PR(2 分钟)

点 [README.md](README.md) 右上角的**铅笔 ✏️**,在下方签名区表格末尾加一行你的名字,依次点 **Commit changes → Propose changes → Create pull request**——走完一次完整的协作流程。维护者会来 review 并合并,你的名字就永久留在这里了。

### 第 3 步(可选):看看别人的 PR

在 **Pull requests** 里逛逛,给同学的 PR 留一句友善的 review——比如"这个提交信息写得清楚 👍"。

## 🤔 常见问题

- **我需要装 Git 吗?** 不用,前两步全程在浏览器完成。
- **提错了怎么办?** 没关系,这里是游乐场;Issue 可以关,PR 可以改——这就是协作的日常。
- **还有别的玩法吗?** 看看 Issues 里别人的许愿——如果你想帮忙实现某个愿望,那就是一次真正的协作开发。
