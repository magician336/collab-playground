# 欢迎来到本仓库!

一个专门用来**练习 GitHub 协作**的仓库——在这里完成你的第一次 Issue、第一次 PR;做得不够标准也没有关系,这正是它存在的意义。

## 参与方式

### 第 1 步:提一个 Issue(约 30 秒)

点上方 **Issues → New Issue**,选择一个模板:

- 🎁 **许愿**:希望这个仓库增加什么内容或功能,欢迎提出建议
- 🙋 **提问**:任何关于 Git、GitHub、多人协作,以及 AI agent、skills 技能集的问题都可以提,别怕问得基础

也可以只写一句自我介绍——任何形式的第一步都值得鼓励。

### 第 2 步:提交你的第一个 PR(约 2 分钟)

点 [README.md](README.md) 右上角的**铅笔 ✏️**,在下方签名区表格末尾加一行你的名字,依次点 **Commit changes → Propose changes → Create pull request**——这样就完整走过一次协作流程。维护者会来 review 并合并,你的名字将永久留在这里。

### 第 3 步(可选):阅读他人的 PR

在 **Pull requests** 页面查看同学的 PR,留一条友善的 review——例如"这个提交信息写得很清楚 👍"。

## 🤔 常见问题

- **我需要装 Git 吗?** 不需要,前两步在浏览器中即可完成。
- **提错了怎么办?** 没有关系。Issue 可以关闭,PR 可以继续修改——这就是协作的日常。
- **还可以做什么?** 阅读 Issues 里他人的许愿;如果你愿意动手实现其中一条,那就是一次真正的协作开发。
